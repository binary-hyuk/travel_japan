# 후쿠오카 가족여행 가이드

2026년 10월 10일~13일, 어른 2명과 23개월 아기의 후쿠오카 3박 4일 여행 가이드입니다. 하나의 HTML 페이지(SPA)로 동작하고, 상단 검색으로 모든 내용을 키워드로 찾을 수 있어요.

- 사이트: https://binary-hyuk.github.io/travel_japan/
- 로컬에서 보기: `index.html`을 브라우저로 열면 됩니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 기능(해시 라우팅, 키워드 검색, 사진 확대, 일본어 ‘크게 보기’, 체크리스트) |
| `content.js` | 가이드 내용 전부. 섹션을 추가하면 검색에 자동으로 잡혀요. 블록 형식은 파일 맨 위 주석 참고 |
| `img/` | 사진. 위키미디어 공용 사진과 공식 사이트 캡처(각 사진에 출처 링크) |

## 내용 추가하기

`content.js`에서 `GUIDE.sections.push({ ... })`로 섹션을 하나 더하면 됩니다. 블록 종류는 `text`, `callout`, `facts`, `table`, `route`, `items`, `gallery`, `timeline`, `phrases`, `say`, `links`, `checklist`예요.

정보는 2026년 10월 초 기준으로 조사했고, 영업시간·요금·운행 시간은 바뀔 수 있으니 방문 전에 각 공식 사이트를 확인하세요.
